# FEISAR by Project MIMICO

Public engineering log of FEISAR, a four-axis robot arm 3D printed at home on planetary reducers of my own design.

- `index.html`: the main page (interactive 3D model, revisions, motion, analyses, method).
- `exploded.html`: scroll-driven disassembly of the arm and its reducers, from the real CAD.

Geometry in `model/` is decimated for the web and is not a manufacturing model. Everything simulated is labelled as simulated.
